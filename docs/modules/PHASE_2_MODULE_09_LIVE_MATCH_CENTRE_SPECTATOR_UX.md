# Phase 2 · Module 09 — Live Match Centre & Spectator Experience

## Added
- Previous/next match navigation within an event.
- Related fixtures around the current match.
- Tournament-timezone match-day deep links back into event schedules.
- URL-synchronised match browser filters (`date` and `status`).
- Current tournament day becomes the default match-browser date when fixtures exist.
- Team names in the scoreboard link to public team profiles.
- Timeline/player-impact rows link to public player/team profiles.
- Event breadcrumb and event links throughout Match Centre.
- Stronger mobile scoreboard layout and full-time result presentation.
- Player-of-the-Match links to the public player profile.

## Integrity / privacy
All navigation is derived from already PUBLISHED matches under the same public tournament/event. No private registration/payment/contact data is added.

## Database
No Prisma schema change.
No new runtime dependency.
